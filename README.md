# Student Performance Analysis 📊

## About
A beginner Data Science project analyzing student performance using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset contains:
- Name
- Age
- Department
- Marks
- Attendance

## Analysis Performed
- Created a Pandas DataFrame
- Exported data to CSV
- Checked dataset information
- Filtered student records
- Sorted students by attendance
- Calculated attendance statistics
- Created data visualizations

## What I Learned
- DataFrames
- Data filtering
- Sorting
- GroupBy
- Basic data analysis
- Data visualization

## Project Goal
To practice Python data analysis skills by exploring student performance data.
